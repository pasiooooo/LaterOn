## LaterOn 能做什么

| 一键添加 | 按项目整理 | 随时继续浏览 |
| --- | --- | --- |
| 按 `Alt+1` 添加当前网页，按 `Alt+Shift+1` 添加所选网页；按 `Alt+2` 添加当前标签组，按 `Alt+Shift+2` 添加整窗网页。 | 添加时选择项目，或者先放进“等待整理”；支持拖拽和多选移动。 | 在全屏界面管理，在浏览器侧栏继续浏览；再次打开网页时可以继续上次滚动位置。 |

LaterOn 会自动提取网页标题、摘要、封面和来源。已经打开的网页不会重复创建标签页，而是直接切换到现有页面。YouTube 按视频 ID 识别同一视频，短链接、播放列表和播放时间参数的差异不会重复打开，也不会重置已打开视频的播放位置。

## 1 分钟安装

LaterOn 目前通过开发者模式安装，支持 Chrome / Edge 121 及以上版本。

1. 打开[最新版本](https://github.com/pasiooooo/LaterOn/releases/latest)，下载 Assets 中的 `LaterOn-版本号.zip` 并解压。
2. 打开 `chrome://extensions/`；Edge 使用 `edge://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后直接包含 `manifest.json` 的文件夹。
5. 建议在扩展菜单中固定 LaterOn，点击图标即可打开侧栏。

## 日常使用

| 操作 | 方式 |
| --- | --- |
| 添加当前网页 | `Alt+1`，或网页右键菜单 |
| 添加当前窗口中所选的全部网页 | `Alt+Shift+1` |
| 添加当前网页所在标签组的全部网页 | `Alt+2` |
| 添加当前窗口全部标签页 | `Alt+Shift+2` |
| 打开 LaterOn | 点击浏览器工具栏图标 |
| 搜索网页 | 地址栏输入 `lo`，按空格后输入关键词 |
| 在新标签页打开 | `⌘/Ctrl + 点击`文章卡片，或使用卡片右键菜单 |

右键 LaterOn 插件图标或网页，也可使用“添加当前网页 / 所选网页 / 当前标签组 / 整窗网页”四种操作，与对应快捷键的添加范围一致。

在 Chrome 标签栏按住 Ctrl（macOS 为 ⌘）点击标签可多选不连续的网页，Shift 点击可选择连续范围，然后按 Alt+Shift+1 添加。所选网页可以跨标签组；只有当前网页被选中时只添加这一页。项目选择框打开后，本次待添加列表保持不变；非 HTTP/HTTPS 标签自动忽略。

“当前标签组”指按快捷键时当前网页所属的 Chrome 标签组，仅添加该组内的 HTTP/HTTPS 网页，按标签顺序处理，并沿用批量添加的项目选择和去重规则。未分组时会提示先加入标签组，不会改为添加整窗网页。

快捷键可以在 `chrome://extensions/shortcuts` 中重新设置。升级会沿用 Alt+1、Alt+2 和 Alt+Shift+1 的已有绑定，其中 Alt+Shift+1 现在添加所选网页，整窗添加的新默认键为 Alt+Shift+2。自定义快捷键会保留；如发生快捷键冲突，可在此页面重新设置。

## 核心体验

- **等待整理**：没想好放在哪里时先添加，之后再统一归类。
- **全部项目首页**：用图板快速浏览所有项目，并直接新建项目。
- **项目快速筛选**：添加网页或移动项目时，可在项目选择面板直接输入名称筛选，支持中英文及回车确认；新建项目输入与筛选分开。网页内的居中添加面板打开时临时隔离网页键盘快捷键，避免 GitHub 等网页抢走焦点；保留打字、中文输入法、复制粘贴及面板内 Tab 切换，关闭后恢复网页快捷键。
- **阅读库 / 书签库**：在侧栏顶端切换两类收藏；书签库与阅读库采用一致的文件夹图板、预览和网页卡片，保留书签的真实层级、面包屑与文件夹内搜索。首次点击“启用并授权”，同步范围默认全部，也可选择一个文件夹及其子文件夹；增删改和网页移动直接反映到当前浏览器书签，浏览器中的修改也会实时反映到书签库。
- **侧栏继续浏览**：点击顶部“添加”将当前网页加入 LaterOn，已有网页显示“已添加”。切换浏览器标签页时，LaterOn 会自动定位到当前网页及其所属项目，并将横向项目栏中选中的项目滚入可视范围；阅读状态等数据刷新会保留当前选择的项目。
- **项目归档**：归档项目会从普通项目列表和搜索中隐藏，可在全屏界面的“归档”中查看、搜索和恢复。归档中的已读网页仍按设置的期限自动清理；删除项目会同时永久删除其中的网页，操作前会确认。
- **阅读状态**：区分未读、在读和已读；已读网页自动清除默认留空、永不清除。设置为 `0` 时立即清除，设置为 `1` 或更大的整数时，在标记已读的相应天数后清除，不设天数上限。已有设置保留不变，清空输入框即可关闭自动清除；正数期限在后台启动、资料或设置变更及每 12 小时定时检查时执行，浏览器关闭期间不会执行。
- **继续上次位置**：重新打开读过的网页时，由你决定是否回到上次滚动位置。
- **批量处理**：多选后可移动、标记、删除，或在一个新窗口中打开。批量删除会先确认，取消时保留勾选，确认后删除本次选中的网页，并一并清理上传封面。添加、修改与删除使用后台最新数据提交；写入失败时保留原数据并提示重试。
- **逐行网址导入**：可直接粘贴每行一个 URL 的列表，或导入 TXT 文件；自动去重并报告无效行，同时兼容原有 JSON 备份。
- **多设备同步**：可连接自己的 WebDAV 服务器，自动同步网页、项目、封面、排序、阅读状态与阅读位置；支持离线编辑和恢复后重试。
- **中英文界面**：可以在设置中切换中文 / English。

### 书签库的使用边界

- 在浏览器侧边栏点击“书签库”，会原位切换到书签侧栏，不会打开新标签页。侧栏提供当前网页添加、搜索、纵向预览卡片及按需展开的文件夹层级；“更多操作”中可新建网页/文件夹、补齐预览及调整同步设置。切回阅读库仍在侧栏内，只有右上角“打开完整界面”会新开书签完整页，并保留当前文件夹。
- 侧栏顶部“添加”先带入当前网页的名称和地址，再由你确认目标文件夹；已在当前同步范围内收藏的网页显示“已收藏”。此按钮写入浏览器书签，不写入阅读库；原有 `Alt+1` 等阅读库快捷键的用途不变。侧栏与完整界面的浏览位置分别保存在本机。
- 左侧展开文件夹树，右侧查看文件夹预览及网页卡片；点击图板或面包屑进入相应层级。文件夹内显示直属网页，搜索时同时查找其后代网页；选择和展开状态仅保存在本机。同步设置在正常连接后收起，可由左下角“同步设置”或顶部连接状态重新打开。
- 封面与摘要优先复用阅读库中的本地信息并独立缓存，没有封面时显示站点占位图。进入书签库不会自动请求收藏网站；点击“补齐当前预览”才请求当前视图最多 12 个网页及其封面，不打开标签页、不执行网页脚本、不使用登录凭据。它是网页封面预览，不是网页截图；需要登录、重定向或动态生成内容的站点可能无法补齐。
- 预览请求拒绝带凭据的网址及可识别的本地、私有地址，也拒绝重定向，但扩展无法验证域名实际 DNS 解析或防止 DNS 重绑定，不提供网络层隔离保证。请求同时最多 2 个、每个响应最多 8 秒；HTML 与图片分别最多读取 256 KiB、512 KiB，预览缓存最多 300 条、8 MiB，不写入浏览器书签、阅读库备份或 WebDAV。
- 在书签库中添加网页并选择目标文件夹，会自动写入对应浏览器书签；可编辑名称和地址、移动网页、新建或重命名文件夹。删除前会确认，并同步删除浏览器中的对应书签。
- 阅读库中的网页可通过卡片右键“存入书签库”或全屏多选后的同名按钮转存；先选择书签目标文件夹，再确认转存。原件保留，目标文件夹中的相同网址不会重复创建；部分失败会逐项记录，重试不会重复创建成功部分。
- 书签库不使用阅读状态，不参与已读网页自动清除，也不受“清空所有网页”、项目删除及阅读库的导入影响。删除书签不会删除阅读库中的原件，清除阅读库原件也不会删除书签。
- 缩小同步范围或停用不会删除浏览器书签。所选文件夹被浏览器删除时会停止操作并提示重新选择范围，不会悄悄改成全部同步；权限撤销后需要重新授权。
- 浏览器根文件夹、当前同步范围的根文件夹和受管理的书签受到保护；LaterOn 只允许删除空文件夹，递归删除请使用浏览器书签管理器。
- 书签及其本机 ID 不写入阅读库的 JSON 备份或 WebDAV；跨设备书签同步由 Chrome / Edge 自身负责，不会把另一台设备的书签树强行覆盖到本机。

## 数据与隐私

- 网页、项目、阅读状态和设置保存在浏览器本地的 `chrome.storage.local` 中；默认不启用云同步。
- LaterOn 不要求注册账号，也不会把添加的网页上传到 LaterOn 服务器。
- 启用 WebDAV 后，同步数据只发送到你配置的服务器；账号密码仅保存在本机，不进入同步文件或导出备份。同步文件是未额外加密的 JSON，请使用 HTTPS 并保护目录权限。
- 可以在设置页中清空网页数据；启用 WebDAV 时，删除也会同步到其他设备。

## 从网址列表导入

在「设置 → 数据」中选择一种方式：

- **导入文件**：选择每行一个 URL 的 `.txt` 文件，或原有 LaterOn `.json` 备份。
- **粘贴 URL 导入**：展开输入框，粘贴网址列表，点击「导入网址」。

```text
https://example.com/article-1
https://example.com/article-2
```

每行需填写完整的 `http://` 或 `https://` 网址。空行会忽略，列表内部和现有收藏中的重复网址会跳过；导入后会显示新增、重复及无效行数量。URL 列表支持 UTF-8（含 BOM），一次最多 5 MB。

新网址会立即作为未读网页进入「等待整理」，后台随后读取网页信息，自动补齐标题、封面、摘要、网站图标和来源。设置页显示处理进度；离开设置页不会中断任务，浏览器重启后会继续处理尚未完成的网址。

提取时优先读取已打开且加载完成的网页；其他网址及缺失的信息通过后台请求网页 HTML 补齐，不会创建、切换或关闭标签页。后台请求不执行网页脚本；无法访问、需要登录、依赖脚本渲染或本身没有相关信息的网页可能无法补齐所有字段，但仍会保留网址。可再次导入相同 URL 重试，也可先手动打开网页，再重新导入以读取页面中的信息。

重复网址不会新增条目，但会补齐已有条目缺失的信息；手动编辑过的标题、摘要、封面，以及阅读状态和所属项目都会保留。含无效行的粘贴文本会保留，方便修改后重试。启用 WebDAV 后，导入的网页及后续补齐的信息也会自动同步到其他设备。

## WebDAV 多设备同步

1. 打开 LaterOn「设置 → 多设备同步 · WebDAV」，填写 WebDAV 服务地址，例如坚果云的 `https://dav.jianguoyun.com/dav/`，以及用户名和密码（或应用专用密码）。使用最终服务地址，不支持重定向。
2. 点击「测试连接」，LaterOn 会自动创建并使用服务地址下的 `LaterOn/` 文件夹，无需手动创建。已有文件夹直接复用；地址已经以 `/LaterOn/` 结尾时不会再嵌套一层。测试会在此文件夹中创建并删除一个临时文件，保留文件夹和已有同步数据。
3. 勾选「启用自动同步」，点击「保存配置」。启用时也会自动创建文件夹并验证连接。每台设备使用同一服务地址和账号，初次同步会合并已有数据。
4. 可点击「立即同步」手动刷新，或查看同步状态与上次成功时间。取消勾选后保存即可暂停；暂停不删除服务器数据，本机改动会在重新启用后继续同步。

云端按天保存与插件导出相同格式的完整 JSON，位于服务地址下的 `LaterOn/` 文件夹：

- 按设备本地日期命名，例如 `lateron-backup-2026-10-13.json`；插件手动导出也采用相同的本地日期规则。
- 同一天有改动时更新同一个文件，内容始终是当天最新的完整数据；无变化时不重复上传，不生成随机名称的增量文件，也不保留当天每次修改的独立历史。
- 第二天首次成功同步时创建新日期的文件，即使数据没有变化也会保留当天的一份完整备份。以前日期的文件不再修改或自动删除。浏览器关闭期间不会补建备份。
- 每份文件都包含网页、项目、自定义封面、排序和阅读位置，可下载后通过「导入」直接导入；沿用导入功能的合并规则，恢复到空收藏库可得到该备份的全部数据。
- 这里的“增量更新”指同一天有变化才更新当天备份；每次写回的是完整 JSON，并非仅传输差异。同步文件上限为 50 MB。

本机连续 **30 秒**无新修改后开始自动同步，每次修改都会重新计时；手动“立即同步”不受此等待限制。浏览器运行时每 **30 秒**检查最新日期的备份，本机有待同步修改时会等到这段静默期结束。后台重启会恢复等待时间。网络、浏览器调度、休眠和退出会影响同步时间。

多设备同步以最新日期文件为准，不把往日备份重新合并进来，避免已删除网页从历史记录中恢复。首次接入会合并两端的收藏；之后依据本机上次成功同步的记录识别新增、修改和删除。主题、语言、快捷键及界面选择仍留在本机。适合在不同设备间依次使用；切换前可点击「立即同步」，新设备读取完成后再开始修改，同时写入同一文件不保证保留全部修改。

新版首次连接只有旧版快照/增量文件的目录时，会合并旧数据并生成当天备份；原有 `lateron-sync-v1.json` 与 `lateron-snapshot-v2-*.json` 保留。一旦每日备份建立，后续仅读取最新日期的备份。**参与同步的设备都应使用本次更新的 1.67.1**，先前使用随机文件名的版本无法读取每日备份。旧配置在重新保存前仍使用原目录，重新保存时采用自动创建 `LaterOn/` 的规则。

同步不依赖 ETag。测试连接会使用临时文件验证目录访问、写入、回读和删除；日常备份直接创建或修改日期文件，不执行历史文件清理。账号密码只保存在本机，不写入备份。修改服务器目录或账号会开始新的同步记录，不会把旧服务器的删除记录带入新服务器。

## 常见问题

### 快捷键按下后没有反应

快捷键可能被系统或其他扩展占用。打开 `chrome://extensions/shortcuts`，为 LaterOn 换一个没有冲突的组合键。网页右键菜单不依赖快捷键，可以作为备用入口。

### 为什么有些页面不能添加？

Chrome 内部页面、扩展商店、浏览器内置 PDF 查看器等受保护页面不允许扩展注入内容。请切换到普通的 `http://` 或 `https://` 网页后再试。

### “加载已解压的扩展程序”提示找不到清单

请选择解压后直接包含 `manifest.json` 的文件夹，而不是它的上一级目录。

### 更新后界面没有变化

将新版安装包的内容覆盖到原来的扩展文件夹，保持原目录不变；回到 `chrome://extensions/`，找到 LaterOn 并点击“重新加载”，然后重新打开侧栏或完整界面。不必先卸载扩展，以免清除本机阅读库数据。

### 侧栏出现在左边，能改到右边吗？

可以。侧栏方向由浏览器控制，在 Chrome 的“设置 → 外观 → 侧栏”中修改。

### 添加面板输入时，网页仍然抢走光标

从 1.71.1 开始，键盘隔离代码在网页加载初期注册。升级后请先在扩展管理页重新加载 LaterOn，再刷新已经打开的 GitHub 等网页一次；只重新打开添加面板，无法让守卫排到旧网页已经注册的快捷键监听器之前。之后面板打开时按键只交给面板，未打开时网页照常接收键盘事件。
