<h1 align="center">LaterOn</h1>

<p align="center"><strong>有价值的网页，留给 LaterOn。</strong></p>

<p align="center">
  <strong>LaterOn 是一款为项目研究而生的网页管理工具。</strong><br />
  把散乱的网页按项目收集、整理和持续处理。
</p>

![LaterOn 全屏项目管理与浏览器侧栏](docs/lateron-overview.webp)

## LaterOn 能做什么

| 一键添加 | 按项目整理 | 随时继续浏览 |
| --- | --- | --- |
| 按 `Alt+1` 添加当前网页，按 `Alt+Shift+1` 添加当前窗口的所有标签页。 | 添加时选择项目，或者先放进“等待整理”；支持拖拽和多选移动。 | 在全屏界面管理，在浏览器侧栏继续浏览；再次打开网页时可以继续上次滚动位置。 |

LaterOn 会自动提取网页标题、摘要、封面和来源。已经打开的网页不会重复创建标签页，而是直接切换到现有页面。YouTube 按视频 ID 识别同一视频，短链接、播放列表和播放时间参数的差异不会重复打开，也不会重置已打开视频的播放位置。

## 1 分钟安装

LaterOn 目前通过开发者模式安装，支持 Chrome / Edge 121 及以上版本。

1. [下载项目 ZIP](https://github.com/gaoyiiiii/LaterOn/archive/refs/heads/main.zip) 并解压。
2. 打开 `chrome://extensions/`；Edge 使用 `edge://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `LaterOn-main` 文件夹。
5. 建议在扩展菜单中固定 LaterOn，点击图标即可打开侧栏。

## 日常使用

| 操作 | 方式 |
| --- | --- |
| 添加当前网页 | `Alt+1`，或网页右键菜单 |
| 添加当前窗口全部标签页 | `Alt+Shift+1` |
| 打开 LaterOn | 点击浏览器工具栏图标 |
| 搜索网页 | 地址栏输入 `lo`，按空格后输入关键词 |
| 在新标签页打开 | `⌘/Ctrl + 点击`文章卡片，或使用卡片右键菜单 |

快捷键可以在 `chrome://extensions/shortcuts` 中重新设置。

## 核心体验

- **等待整理**：没想好放在哪里时先添加，之后再统一归类。
- **全部项目首页**：用图板快速浏览所有项目，并直接新建项目。
- **侧栏继续浏览**：点击顶部“添加”将当前网页加入 LaterOn，已有网页显示“已添加”。切换浏览器标签页时，LaterOn 会自动定位到当前网页及其所属项目，并将横向项目栏中选中的项目滚入可视范围；阅读状态等数据刷新会保留当前选择的项目。
- **项目归档**：归档项目会从普通项目列表和搜索中隐藏，可在全屏界面的“归档”中查看、搜索和恢复。归档中的已读网页仍按设置的期限自动清理；删除项目会同时永久删除其中的网页，操作前会确认。
- **阅读状态**：区分未读、在读和已读；已读内容默认 30 天后自动清理，可在设置中调整。
- **继续上次位置**：重新打开读过的网页时，由你决定是否回到上次滚动位置。
- **批量处理**：多选后可移动、标记、删除，或在一个新窗口中打开。批量删除会先确认，取消时保留勾选，确认后删除本次选中的网页，并一并清理上传封面。添加、修改与删除使用后台最新数据提交；写入失败时保留原数据并提示重试。
- **逐行网址导入**：可直接粘贴每行一个 URL 的列表，或导入 TXT 文件；自动去重并报告无效行，同时兼容原有 JSON 备份。
- **多设备同步**：可连接自己的 WebDAV 服务器，自动同步网页、项目、封面、排序、阅读状态与阅读位置；支持离线编辑和恢复后重试。
- **中英文界面**：可以在设置中切换中文 / English。

## 数据与隐私

- 网页、项目、阅读状态和设置保存在浏览器本地的 `chrome.storage.local` 中；默认不启用云同步。
- LaterOn 不要求注册账号，也不会把添加的网页上传到 LaterOn 服务器。
- 启用 WebDAV 后，同步数据只发送到你配置的服务器；账号密码仅保存在本机，不进入同步文件或导出备份。同步文件是未额外加密的 JSON，请使用 HTTPS 并保护目录权限。
- 可以在设置页中清空网页数据；启用 WebDAV 时，删除也会同步到其他设备。

## 从网址列表导入

在「设置 → 数据」中选择一种方式：

- **导入文件**：选择每行一个 URL 的 `.txt` 文件，或原有 LaterOn `.json` 备份。
- **粘贴 URL 导入**：展开输入框，粘贴网址列表，点击「导入网址」。

```text
https://example.com/article-1
https://example.com/article-2
```

每行需填写完整的 `http://` 或 `https://` 网址。空行会忽略，列表内部和现有收藏中的重复网址会跳过；导入后会显示新增、重复及无效行数量。URL 列表支持 UTF-8（含 BOM），一次最多 5 MB。

新网址会立即作为未读网页进入「等待整理」，后台随后使用与正常添加网页相同的提取逻辑，自动补齐标题、封面、摘要、网站图标和来源。设置页显示处理进度；离开设置页不会中断任务，浏览器重启后会继续处理尚未完成的网址。

提取时优先复用已打开的网页；其他网址会逐个在静音、不抢焦点的临时标签页中加载，提取后自动关闭。如果你切换到临时标签页阅读，该标签页会保留。无法访问、需要登录或本身没有相关信息的网页仍会保留网址，可再次导入相同 URL 重试补齐。

重复网址不会新增条目，但会补齐已有条目缺失的信息；手动编辑过的标题、摘要、封面，以及阅读状态和所属项目都会保留。含无效行的粘贴文本会保留，方便修改后重试。启用 WebDAV 后，导入的网页及后续补齐的信息也会自动同步到其他设备。

## WebDAV 多设备同步

1. 打开 LaterOn「设置 → 多设备同步 · WebDAV」，填写 WebDAV 服务地址，例如坚果云的 `https://dav.jianguoyun.com/dav/`，以及用户名和密码（或应用专用密码）。使用最终服务地址，不支持重定向。
2. 点击「测试连接」，LaterOn 会自动创建并使用服务地址下的 `LaterOn/` 文件夹，无需手动创建。已有文件夹直接复用；地址已经以 `/LaterOn/` 结尾时不会再嵌套一层。测试会在此文件夹中创建并删除一个临时文件，保留文件夹和已有同步数据。
3. 勾选「启用自动同步」，点击「保存配置」。启用时也会自动创建文件夹并验证连接。每台设备使用同一服务地址和账号，初次同步会合并已有数据。
4. 可点击「立即同步」手动刷新，或查看同步状态与上次成功时间。取消勾选后保存即可暂停；暂停不删除服务器数据，本机改动会在重新启用后继续同步。

同步快照位于服务地址下的 `LaterOn/` 文件夹，文件名为 `lateron-snapshot-v2-<随机标识>.json`。旧版已保存的目录配置在重新保存前仍按原路径同步，避免升级后突然切换位置；重新保存时采用新的 LaterOn 文件夹规则，请一并更新其他设备的配置。旧目录文件不会自动移动或删除。

本机修改后约 **1.2 秒**触发上传，浏览器运行时每 **30 秒**检查其他设备的改动。WebDAV 使用轮询，因此属于近实时同步；网络耗时、浏览器调度、休眠和关闭都会影响到达时间。后台服务被回收后，定时任务和下次启动会继续同步，断网时仍可在本地整理。

- 同步范围：网页与阅读状态、项目（含归档与置顶）、封面、项目与卡片顺序、阅读位置。主题、语言、快捷键及当前页面选择留在本机。
- 合并规则：不同 ID 的记录保留各自的改动；同一条记录冲突时按修改版本（设备时间与设备标识）确定胜者，不能保留同一条记录上同时发生的所有字段修改。新设备首次接入时，已同步过的同 ID 记录优先。请保持设备时间准确。
- 删除记录会保留在同步文件中，防止长期离线设备带回旧数据。删除、已读自动清理与「清空所有网页」也会传播。同步不能替代备份，重要数据建议定期导出。
- 同步不依赖 ETag 或条件写入。服务器需支持 WebDAV 目录枚举（`PROPFIND`）、创建目录（`MKCOL`）和文件读写删除；连接测试会实际验证目录访问、写入、回读和删除。
- 每次发布使用新的随机快照文件名，多设备并发写入不会覆盖彼此的文件。读取并合并快照中的条目版本及删除记录后，先上传、回读验证，再清理已被新快照完整包含的旧快照。没有变更时不重复上传，清理失败时保留快照并在下次重试；单个快照最大 50 MB。
- 开发测试期间的 `lateron-sync-v1.json` 会作为只读数据源合并，原文件不修改、不删除。**所有参与同步的设备请使用包含快照同步的 1.67.0 正式版**；早期使用单文件同步的开发测试版本无法读取新的快照文件。
- 修改服务器目录或账号会开始新的合并记录，不会把旧服务器的删除记录带入新服务器。密码变更不重置记录。

## 常见问题

### 快捷键按下后没有反应

快捷键可能被系统或其他扩展占用。打开 `chrome://extensions/shortcuts`，为 LaterOn 换一个没有冲突的组合键。网页右键菜单不依赖快捷键，可以作为备用入口。

### 为什么有些页面不能添加？

Chrome 内部页面、扩展商店、浏览器内置 PDF 查看器等受保护页面不允许扩展注入内容。请切换到普通的 `http://` 或 `https://` 网页后再试。

### “加载已解压的扩展程序”提示找不到清单

请选择解压后直接包含 `manifest.json` 的文件夹，而不是它的上一级目录。

### 更新后界面没有变化

回到 `chrome://extensions/`，找到 LaterOn 并点击“重新加载”，然后重新打开侧栏或完整界面。

### 侧栏出现在左边，能改到右边吗？

可以。侧栏方向由浏览器控制，在 Chrome 的“设置 → 外观 → 侧栏”中修改。
